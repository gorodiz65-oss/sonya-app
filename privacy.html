Политика конфиденциальности мини-приложения «Кошка Соня»

1. Какие данные используются

Приложение получает от платформы имя пользователя и использует его для приветствия. Фото профиля в приложении не запрашивается и не используется. Отдельной регистрации нет.

2. Где хранятся данные

Игровой прогресс (баллы, дни, бейджи и отметки об играх) хранится локально в браузере и, при запуске приложения на платформе, в пользовательском хранилище мини-приложения. Это нужно для синхронизации прогресса между поддерживаемыми версиями приложения. Для синхронизации данные передаются платформе. Собственные серверы для хранения прогресса приложение не использует.

3. Файлы cookie

Приложение само не устанавливает cookie. Браузер, хостинг и платформа могут использовать технические механизмы, необходимые для их работы.

4. Удаление данных

Очистка данных сайта удаляет локальную копию прогресса из браузера. Для удаления данных из пользовательского хранилища платформы обратитесь в сообщения сообщества «Кошка Соня».

5. Контакты

По вопросам конфиденциальности обращайтесь в сообщения группы «Кошка Соня»: vk.ru/catsonya_off
